# Social Media App

This is a simple social media application built with React and Vite. The app allows users to view posts, create new posts, and explore a basic UI with a sidebar, header, and footer.

## Features

- **Post List**: Fetch and display posts from an external API.
- **Create Post**: Add new posts with a title, body, and tags.
- **Sidebar Navigation**: Switch between "Home" and "Create Post" views.
- **Responsive Design**: Styled with Bootstrap for a clean and responsive layout.
